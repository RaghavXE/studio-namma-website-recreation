# Studio Namma Website Recreation

A recreation of the Studio Namma website built to explore modern frontend development techniques, interactive user experiences, and creative web design patterns.

## Features

- Interactive mouse follower
- Custom cursor effects
- Blur animations
- Video sections
- Responsive layout
- Modern typography
- Agency-style landing page design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Purpose

This project was created as a frontend development exercise to better understand advanced website interactions, animations, and modern design trends used by creative agencies.
